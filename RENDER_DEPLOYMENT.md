# Render.com Deployment Instructions

## 🚀 Quick Deployment to Render.com

### Prerequisites
- GitHub account
- Render.com account (free tier available)
- Your code pushed to GitHub

### Steps to Deploy

#### 1. **Push Code to GitHub**
```bash
# Initialize git if not already done
git init

# Add all files
git add .

# Commit
git commit -m "Initial commit - Ready for deployment"

# Add your GitHub repository
git remote add origin https://github.com/yourusername/businessdiary.git

# Push to GitHub
git push -u origin main
```

#### 2. **Deploy on Render.com**

**Option A: Using render.yaml (Recommended)**
1. Go to https://render.com/
2. Sign in with GitHub
3. Click "New +"
4. Select "Blueprint"
5. Connect your GitHub repository
6. Render will automatically detect `render.yaml`
7. Click "Apply" to create all services

**Option B: Manual Setup**
1. Create PostgreSQL database first
2. Create Backend Web Service
3. Create Frontend Static Site
4. Link services together

#### 3. **Configure Services**

**Backend API Settings:**
- Name: `businessdiary-api`
- Environment: `Python 3`
- Build Command: 
  ```bash
  cd backend && pip install -r requirements.txt && python recreate_db.py && python add_categories.py && python add_subcategories.py && python populate_data.py && python assign_businesses_to_subcategories.py
  ```
- Start Command: 
  ```bash
  cd backend && gunicorn -w 4 -b 0.0.0.0:$PORT wsgi:app
  ```

**Frontend Static Site Settings:**
- Name: `businessdiary-frontend`
- Build Command: 
  ```bash
  cd frontend && npm install && npm run build
  ```
- Publish Directory: `frontend/build`

**Environment Variables for Backend:**
```
FLASK_ENV=production
SECRET_KEY=<auto-generated>
JWT_SECRET_KEY=<auto-generated>
DATABASE_URL=<from-database>
PYTHON_VERSION=3.11.0
```

**Environment Variables for Frontend:**
```
REACT_APP_API_URL=https://businessdiary-api.onrender.com
```

#### 4. **Update Frontend API URL**

After backend is deployed, update the frontend environment variable:
1. Go to frontend service settings
2. Add environment variable:
   - Key: `REACT_APP_API_URL`
   - Value: Your backend URL (e.g., `https://businessdiary-api.onrender.com`)
3. Trigger manual deploy

#### 5. **Test Your Deployment**

Visit your frontend URL:
- Frontend: `https://businessdiary-frontend.onrender.com`
- Backend API: `https://businessdiary-api.onrender.com/api/categories`

## 🔧 Troubleshooting

### Issue: Backend fails to start
**Solution:** Check logs in Render dashboard
```bash
# Common issues:
- Missing environment variables
- Database connection failed
- Python version mismatch
```

### Issue: Frontend can't connect to backend
**Solution:** Update `REACT_APP_API_URL` environment variable
```
REACT_APP_API_URL=https://your-backend.onrender.com
```

### Issue: Database tables not created
**Solution:** Re-run build command or check migration logs

### Issue: CORS errors
**Solution:** Backend already configured for CORS, ensure API URL is correct
